HTML Lists and Tables

This page explains the concepts of Lists and Tables in HTML, starting from beginner level to advanced with examples.

1. HTML Lists

Lists allow us to organize content in a structured format. HTML provides three main types of lists:

1.1 Unordered List (<ul>)

Used when the order of items does not matter. Items are marked with bullets.

  • Apple
  • Banana
  • Orange

1.2 Ordered List (<ol>)

Used when the order of items matters. Items are automatically numbered.

  1. Wake up
  2. Brush teeth
  3. Go to college

1.3 Nested List

Lists can be placed inside another list to create sub-items.

  • Programming Languages
    1. Python
    2. C++
    3. Java
  • Databases
    • MySQL
    • MongoDB

Nested Table Example


<table t;
      Outer Cell 1
      <table t;
          <td>Inner 1</td>
          <td>Inner 2</td>
        </tr>
      </table>
    </td>
    <td>Outer Cell 2</td>
  </tr>
</table>

1.4 Description List (<dl>)

Used to define terms and their descriptions.

2. HTML Tables

Tables are used to arrange data in rows and columns.

2.1 Basic Table

A simple table with rows and columns:

Math 90
Science 85

Table Example Code


<table >Subject</th>
    <th>Marks</th>
  </tr>
  <tr>
    <td>Math</td>
    <td>90</td>
  </tr>
  <tr>
    <td>Science</td>
    <td>85</td>
  </tr>
</table>

2.2 Table with Header, Body, and Footer

Tables can be divided into header (<thead>), body (<tbody>), and footer (<tfoot>).

Price
Laptop $800
Phone $500
Total $1300

Table Code Example


<table t;
      <th>Product</th>
      <th>Price</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Laptop</td>
      <td>$800</td>
    </tr>
    <tr>
      <td>Phone</td>
      <td>$500</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td><b>Total</b></td>
      <td><b>$1300</b></td>
    </tr>
  </tfoot>
</table>

2.3 Table with Colspan and Rowspan

colspan merges columns, and rowspan merges rows.

Scores
Math Science
Alex 95 88
Sara 89 92

Rowspan and Colspan Table Example


<table owspan="2">Name</th>
    <th colspan="2">Scores</th>
  </tr>
  <tr>
    <th>Math</th>
    <th>Science</th>
  </tr>
  <tr>
    <td>Alex</td>
    <td>95</td>
    <td>88</td>
  </tr>
  <tr>
    <td>Sara</td>
    <td>89</td>
    <td>92</td>
  </tr>
</table>

2.4 Nested Table

One table can be placed inside another.

Inner 2
Outer Cell 2

Nested Table Example


<table t;
      Outer Cell 1
      <table t;
          <td>Inner 1</td>
          <td>Inner 2</td>
        </tr>
      </table>
    </td>
    <td>Outer Cell 2</td>
  </tr>
</table>

Conclusion

In this tutorial, we covered:

  • Different types of lists: unordered, ordered, nested, and description lists.
  • Different types of tables: basic, advanced with header/body/footer, colspan, rowspan, and nested tables.
Mastering these concepts will help you create structured and readable webpages.
